# Лабораторная работа: поиск молодых защитников в массиве структур

## Условие задачи

Задан массив из 10 структур `Players`. Каждая структура описывает футболиста: фамилия, дата рождения, клуб, амплуа, количество сыгранных матчей, место рождения.

Необходимо найти и вывести на экран всех игроков, которые удовлетворяют одновременно трём условиям:

- амплуа — **защитник**;
- возраст — **младше 20 лет**;
- количество сыгранных матчей — **более 40**.

Возраст вычисляется как разность между текущим годом (2026) и годом рождения.

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. Установить локаль `Russian` для корректного вывода кириллицы.
3. Объявить структуру `Players` с полями:
  - `sdname` — фамилия;
  - `birthDate` — дата рождения в формате `ДД.ММ.ГГГГ`;
  - `club` — клуб;
  - `position` — амплуа;
  - `matches` — количество матчей;
  - `birthPlace` — место рождения.
4. Инициализировать массив `players[10]` данными игроков.
5. Вывести заголовок и условия поиска.
6. Обнулить счётчик найденных игроков: `found` = 0.
7. Для `i` от 0 до 9 выполнить:
  - вычислить возраст `age` = `get_age(players[i].birthDate)`, где функция `get_age` выделяет из даты год рождения и возвращает `2026 - год` (если год выделить не удалось — возвращает 0);
  - если `position` = «Защитник» **и** `age` < 20 **и** `matches` > 40, то вывести все данные игрока и увеличить `found` на 1.
8. После завершения цикла:
  - если `found` = 0 — вывести сообщение «Игроков, подходящих под условия, не найдено»;
  - иначе — вывести «Всего найдено игроков: `found`».
9. **Конец**

## 2. Реализация программы

```c
#define _CRT_SECURE_NO_WARNINGS
#include<stdio.h>
#include<string.h>
#include<locale.h>	
struct Players{
	char sdname[50];
	char birthDate[15];
	char club[50];
	char position[30];
	int matches;
	char birthPlace[50];
};
int get_age(const char* birthDate) {
    int day, month, year;
    if (sscanf(birthDate, "%*d.%*d.%d", &year) == 1) {
        return 2026 - year;
    }
    return 0;
}
int main() {
    setlocale(LC_ALL, "Russian");
    struct Players players[10] = {
    {"Иванов", "15.05.2007", "Зенит", "Защитник", 45, "Санкт-Петербург"},
    {"Смирнов", "22.11.2003", "Спартак", "Защитник", 52, "Москва"},
    {"Кузнецов", "10.08.2006", "ЦСКА", "Защитник", 12, "Москва"},
    {"Морозов", "05.05.2008", "Локомотив", "Защитник", 55, "Москва"},
    {"Васильев", "19.07.2007", "Динамо", "Защитник", 41, "Москва"},
    {"Волков", "17.11.2007", "Сочи", "Защитник", 48, "Сочи"},
    {"Соколов", "05.12.2006", "Краснодар", "Защитник", 8, "Краснодар"},
    {"Михайлов", "14.04.2008", "Рубин", "Защитник", 44, "Казань"},
    {"Новиков", "30.01.2008", "Ахмат", "Защитник", 42, "Грозный"},
    {"Федоров", "11.10.2001", "Балтика", "Защитник", 70, "Калининград"}
    };
    printf("--- РЕЗУЛЬТАТЫ ПОИСКА ---\n");
    printf("Условия: Защитники, младше 20 лет, более 40 матчей.\n\n");

    int found = 0;
    for (int i = 0; i < 10; i++) {
        int age = get_age(players[i].birthDate);
        if (strcmp(players[i].position, "Защитник") == 0 &&
            age < 20 &&
            players[i].matches > 40) {

            printf("Фамилия: %s\n", players[i].sdname);
            printf("Дата рождения: %s (Возраст: %d)\n", players[i].birthDate, age);
            printf("Клуб: %s\n", players[i].club);
            printf("Амплуа: %s\n", players[i].position);
            printf("Количество игр: %d\n", players[i].matches);
            printf("Место рождения: %s\n", players[i].birthPlace);
            printf("-----------------------------------\n");
            found++;
        }
    }
    if (found == 0) {
        printf("Игроков, подходящих под условия, не найдено.\n");
    }
    else {
        printf("Всего найдено игроков: %d\n", found);
    }

    return 0;
}
```
